# Contribuir

Gràcies per ajudar a millorar GM AI.

1. Crea una branca a partir de `main`.
2. Mantén el domini independent de FastAPI, SQLite i el proveïdor LLM.
3. No permetis que una resposta del LLM modifiqui directament l'estat del món.
4. Afegeix o actualitza proves per a cada regla nova.
5. Executa les validacions indicades al README abans d'obrir una pull request.
6. No incloguis secrets, bases de dades locals ni contingut editorial sense permís.

Els commits poden seguir Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`).
